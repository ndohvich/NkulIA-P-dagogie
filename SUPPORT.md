# Obtenir de l'aide

## Avant de demander

1. Consultez `README.md` pour l'installation et le démarrage rapide.
2. Consultez `docs/ARCHITECTURE.md` pour comprendre les principes de conception.
3. Cherchez dans les [issues existantes](https://github.com/ndohvich/NkulIA-Pedagogie/issues) (ouvertes et fermées) — votre question a peut-être déjà une réponse.

## Poser une question

Ouvrez une issue avec le modèle **❓ Question** (`.github/ISSUE_TEMPLATE/question.yml`).

## Signaler un bug

Ouvrez une issue avec le modèle **🐛 Signalement de bug**, en suivant
la checklist (étapes de reproduction, module concerné, contexte réseau).

## Proposer une fonctionnalité

Ouvrez une issue avec le modèle **✨ Demande de fonctionnalité**, en
précisant le problème pédagogique ou technique résolu — pas seulement
la solution envisagée.

## Ce projet n'a pas de canal de support commercial

NkulIA est un projet pédagogique développé par un enseignant pour des
enseignants. Il n'y a pas de SLA, de hotline ni de support payant.
